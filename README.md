# Aica Alien Food — One Star, Five Stars for the Food

An entry for the [make.fun](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7?ref=38m33ybw)
competition "One Star, Five Stars for the Food".

`main.py` writes a single sentence to `/output/entry.txt`: a one-star
review of planet Earth by an alien tourist that still slips in a real
compliment about the food — the sun sets without asking permission,
gravity bruises a third knee, the locals queue to stare at glowing
rectangles, but the tacos alone nearly justify the fuel home.

## Run

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` (creating `/output` if
needed). The output is deterministic: byte-identical on every run.
Python 3.13, standard library only, no network access.
